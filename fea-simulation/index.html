- Abaqus -

- What is Abaqus

  • Abaqus is a software suite that can be used for finite element analysis and computer-aided engineering. It can be used to model and analyze mechanical components and assemblies, and to visualize the results of finite element analysis.
  • Abaqus serves as my go-to tool for finite element simulations. In addition, I occasionally utilize Ansys Workbench and LS-Dyna, which have functionalities that are largely comparable.

- Hypermesh -

- What is Hypermesh

  • Altair HyperMesh, part of the Altair HyperWorks environment, is a finite element modeling preprocessor that allows users to produce fine-tuned, high-quality surface meshes of their CAD geometry.
  • I primarily use this software for meshing geometry. I've recorded some meshing cases using Hypermesh.
