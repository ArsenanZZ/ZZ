RUN50 · 第16州

深冬起跑，大奖牌向我招手

二月中旬的肯塔基，还在冬天的尾巴里打转。

天灰风冷，阳光像抹布一样稀薄。

这个冬天我和 Norton 一起训练，感觉状态挺好。

于是琢磨着找一场不太远的马拉松，来测试一下冬训成果，

就像期中考试，跑者版。

我们翻着比赛列表，一眼就被这场 「Run Oak Island Marathon」 吸住了。

奖牌特别大，像挂在墙上的金属罗盘，

不仅质感拉满，还自带“海边风味”。

更重要的是，它就在北卡最东南的尽头，一块叫 橡树岛（Oak Island）的地方。

地图上看，那地方已经探进了大西洋，

于是我们从「路易斯维尔」启程，

一路往东南开，一路从内陆向海边靠近。

计划在橡树岛跑个马，把 「北卡」，这第16州打上卡。

03

RUN50 · 第16州

大陆与大西洋的交界处

🏝Oak Island, NC

美国东南部，有一片狭长的岛屿，叫做 Oak Island（橡树岛）。

它属于 北卡罗来纳州（North Carolina） 的 Brunswick County，

面朝大西洋，背靠内水道，风大、海阔、人少。

我们在这儿跑马，是为了奖牌，是为了验收冬训，

也是为了 Run50 系列里的 第16个州：「北卡罗莱纳」。

作为名字里带 “北” 的州，North Carolina 常常被和「南卡」搞混。

但这州可不简单：

第一架飞机从这儿起飞：1903年，莱特兄弟就在北卡外滩完成人类首次飞行。

大学篮球爆强：UNC 和 Duke，NCAA历史最强的死对头组合。

美东最长海岸线之一：沿大西洋绵延 300 多英里，从灯塔到沙洲，从军港到国家公园。

横跨群山到大海：西部是蓝岭山（Appalachian Mountains），东部就是大西洋。

Oak Island 正是这个 “大海那头” 的一角，

在这里跑马，就像从美洲大陆一路奔向海的尽头。

04

RUN50 · 第16州

从内陆出发，一路驶向北卡

📣Oak Island, NC

Day 1｜Kentucky → Tennessee → Smoky Mountains

2月的肯塔基还挺冷的，我们把行李塞进后备箱，启程出发。

第一晚我们落脚在 Smoky Mountains 附近的 Newport，一家 Econo Lodge。

小镇安静得像一张旧明信片，空气里有种“旅程刚开始”的期待感。

Day 2｜Smoky Mountains → Wilmington → Oak Island

从山里出发，一路往南，越开越湿润。

沿途经过 Asheville、Charlotte，再一路向东，接近海岸线。

下午五点左右，我们抵达了 Run Oak Island Marathon 的博览会现场。

时间不早，属于“收摊前的最后几波人”。

会场不大，一眼望到底，几排桌子和纸箱。志愿者大多是本地居民，操作熟练，笑容亲切。

扫码、发包、一切流畅得像家门口的社群活动。

我们顺利领到了比赛包，顺便也看了眼主办方展示的奖牌系列。

这场赛事隶属 BAM! Race Series（Big Ass Medal Race Series），是北卡几个海岛联合举办的系列马拉松。

包括：

Run Oak Island（橡树岛）

Run Sunset Beach（日落海滩）

Run Holden Beach（霍尔登海滩）

每一场比赛的奖牌都非常大、非常有设计感，像是一块可以挂墙的金属雕塑。

怪不得不少跑者会一次报三场，专门来“集齐一套”。

领完装备后，天色已暗，我们在 Wilmington 小镇找了家评分不错的泰国餐厅Indochine Express。

这家店外观像美剧里的经典小木屋，里面却藏着一锅香喷喷的红咖喱。

椰香浓郁、辣劲十足，搭配清爽的沙拉和白米饭，跑前补碳水，刚刚好。

晚上回到 Airbnb，简单整理装备、第二天，就要 Run Oak Island 了。

05

RUN50 · 第16州

出发！跑在海岛清晨的阳光下

📣Oak Island, NC

比赛日早晨：起跑线上的小插曲☀️

比赛当天早晨，我们起得很早，但没料到从 Airbnb 到起点的车程比预想中久。

当我们赶到起跑区域时，第一波半马选手已经出发，现场人潮涌动，音乐和鼓点响彻空气。

天气非常好。清晨的海风不冷不热，阳光柔和，是跑马最理想的状态之一。

路线简介：Oak Island Marathon & Half 🗺

全马路线是一个完整的环岛穿越，从岛西南角的 Dolphin Drive 起跑，经过东海岸、中部内陆，一路贴着内水道和大西洋海岸线，最后回到出发点，全程景色相当丰富。

半程马拉松则分为两个版本：

East Course（东线）：起跑时间是 6:45 AM，和全马同时出发

West Course（西线）：起跑时间是 7:15 AM，比前者晚半小时

Siqi 报的是半马东线，也就是 6:45 出发，而我是要跑 “全马” 的。

但由迟到了，再加上停车耽误，等我们抵达现场，全马和第一波半马已经出发了一阵。

西线半马开跑还有一阵，我就想着跟着这波人起跑吧，顺便整理整理手机和号码布。

Siqi就选择赶紧出发了，去追东线半马的跑者了，走的时候还提醒我西线半马和全马路线不一样。

迎着小岛的阳光出发，还挺好，我没有跑错，在一个路口从半马赛道分离，准确切回了全马主路线。

岛清晨的开场白：阳光、飞鸟、小别墅，和一条看不见海的路🎽

这时候，路上人不多，清晨的橡树岛有一种宁静的热情。

色彩斑斓的海边小屋一栋接一栋，木质结构的墙体反射着阳光，树影在脚下摇晃。

跑着跑着，在第一英里左右，我就追上 Siqi 了。

我们在路中间暂停了一下，在阳光下举着摄像头互相拍照。

整理好节奏，我继续奔向前跑了，去追大部队。

绕过一片转角后，又终于遇到了几位全马跑者，这会儿还不到两英里，

我开始重新融入大部队节奏了，可以好好享受这趟 “冲向大西洋” 的旅程了。

吹着海风往前跑，虽然这条路线大部分时间其实 “看不到”海，但那种潮湿、微咸的空气，一闻就知道离大西洋不远了。

阳光温柔不刺眼，洒在身上倒像是早晨的按摩。

跑到第3英里，路线左转，穿进一个安静的居民区，小区岔路多，人也多了起来，开始有半马的选手和我“并轨”，他们大多是从小区另一头折返回来的。

从这个社区出来后，迎面就看到一个大牌子写着：Caswell Dunes，

这是个紧邻海滩的高尔夫社区，以风景好、环境静著称，跑在这里，路面宽阔平整，两边是修剪整齐的草地和一栋栋风格一致的小别墅。

往东北方向继续跑，阳光斜洒过来，天空中还能看到几只飞鸟在滑翔。

大约在7~8英里的时候，我终于来到了 Oak Island 的地标性建筑：Oak Island Lighthouse（橡树岛灯塔）

建于1958年，高约153英尺（约47米），外观是典型的三段渐变色涂装：底部深灰，中部白色，顶部黑色。虽然不算古老，但它是全美少数几个仍由原始灯塔系统运作的灯塔之一。

它的灯光能照射到16海里外，是航海者重要的引导标志。

这座塔之所以特别，不仅因为它仍在服役，还因为它的涂装不靠 “刷漆”

而是当年浇筑混凝土时就直接把颜色掺进去的。也就是说，它永远不需要重新粉刷，算是灯塔届的“黑科技”。

比赛在灯塔前不远处设了一个折返点，那里有摄影师在为选手拍照。

我调整了下呼吸，摆了个姿势，顺便比了个飞翔的姿势，老年人造型？

转身折返，迎面而来的选手一个个面带笑容，不知道是因为灯塔，还是因为这段平坦开阔的路，让大家都轻松了不少。

灯塔前折返点就在9英里出头的位置，刚过不久，我就看到 Siqi 跑来了，

这回是 “没戴眼镜的47”，笑眯眯地朝我挥手，整个人看起来还挺轻松。

天空依旧灰蒙蒙的，太阳像披了层纱窗，不刺眼，反倒给赛道铺上了一层柔和的滤镜。

路边还有一些自发志愿者，架着小桌子发水，发 “可乐，发威士忌”。

消防车上几位消防员坐在前杠上，悠哉地给我们加油助威，小岛的悠闲和随性，在这一刻展露无遗。

跑过那家摆满冲浪板和鲨鱼模型的商店，14 英里到了。我们又贴近海边，但视线还是被一排排房子挡住。

天上有几只海鸟在盘旋，偶尔有观众举牌加油，气氛轻松。

路边晒着几辆老爷车，像静止在阳光里的风景。

17 英里时，太阳出来了，天气有点热了。

阳光照在彩色小房子上，把整条路染得鲜亮温暖，我在热风里继续前行，海岛的宁静和炽热交织在一起。

硬桥硬马干到终点｜美国 PB + 大奖牌，一样不落🎖️

跑到21英里，瞄了眼手表，节奏意外地稳。只要不作妖、不抽风，慢慢巡航，破4问题不大。

于是心里一合计：行吧，那就认真点，别演了。

前方是座大桥，看着不长，坡却挺陡。我边跑边想，这桥也太不讲理了，放21英里了。

但腿还听听话，说明冬训确实干货不少。

桥头一拐，开始折返，下坡也不轻松，

不过那会儿我脑子已经被 “我要破四” 这句话塞满了，于是闭眼一冲，3小时51分钟，终点见！这是我在美国目前跑过的最好成绩了，

跑步是个挺傻的运动，但稍微认真训练一下，就能看到进步。

冲线前，在终点不远处有观众在鼓掌，我举起双臂冲线，像是给自己比了个“耶”。

奖牌特别大，金属感厚实得能当锅盖用，中间是个指南针，各个方向清晰可见，还有浪花的雕刻，边缘带锯齿。

晃在脖子上咣当咣当，比我脸都大，不愧是 BAM! Race Series: Big Ass Medal，名副其实。

Siqi那边早就收工，我去领了个BBQ汉堡，

吃饱喝足，

我们俩掏出小飞机（Hover X1），

在停车场边和一个路边餐厅前拍了一组「跑完奖牌炫耀大片」，

背景是一整面彩绘墙：五颜六色的大鱼、海浪、红色浮标，还有一艘白色捕虾船，整幅画色彩饱满、线条粗犷、海味十足。

我不禁想了《阿甘正传》里布巴开的那家“布巴虾公司”（Bubba Gump Shrimp Co.）餐厅。

如果那家店也开在Oak Island，大概也会有这么一面墙吧，画着海鱼、船只，还有几个穿背心戴棒球帽的“阿甘”在海风里甩着虾网，

说不定还写着一句台词：

“Stupid is as stupid does.”（傻人有傻福。）

或者 “Life is like a box of medals.”

墙上标着“49th Street”，我们也就此留下了属于我们「第16州」的一堆照片，

哦，不对， Siqi 是第15个州，比我还少一个。

RUN50 · 第16州

跑完16州，吃一口味精版乡愁，再写段旅途rap！

接着我们开车去Planet Fitness洗了个澡，这是我们马拉松旅行的“标准流程”。干净清爽之后，照例是觅食时间。

开了会儿车，我们选了一家美式中餐自助。只要你在美国生活过一段时间，就会发现这种餐厅有种魔力般的复制粘贴感：装潢大同小异，菜品更是全国通用模板。

橙汁鸡、芥兰牛、炸云吞、蟹脚棒、春卷，还有甜点区的水果罐头和明胶布丁，味道统一得像 Ctrl+C / Ctrl+V，一入口，乡愁和味精齐飞。

这类餐厅背后，其实藏着一段福建移民的创业故事：

上世纪80、90年代，许多福建人漂洋过海来到美国，从打工做起，慢慢积累经验后，开始扎根小镇，开起了自助餐厅。他们用最接地气的口味和最平易近人的价格征服了美国中部与南方的胃。

菜单不是给中国人设计的，而是调成了“老美版中餐”。你说它不地道吧，但它又在美国扎扎实实活成了“地道”。

那晚我们在一间公路边的酒店住下。早餐就是标准的“美式套餐”：

纸盒鸡蛋、煎香肠、waffle机自助烤饼、橙汁咖啡任你取，虽然没中式那种粥小菜、包子油条的烟火气，但在路途中吃个热早餐，也算不错。

返程我们穿越北卡和弗吉尼亚的山路，天宽地阔，阳光斜洒，一路风景如画。

进了西弗吉尼亚，山顶上竟还有没化完的积雪，像是给这次跑步旅行的末尾加了一笔冬日余韵。

旅途最后，总结一下，来一段 rap！

Country Road 带我回到 KY，跑完16州我只想 high five！

灯塔做证，U.S. PB 刷新，3小时51分，我不是在拼命，是在认真！

站壁画前像是穿越《阿甘正传》的画，中餐buffet全美都一个味，

但每一州的汗水，味道都不一样 对不对？

Run50 不止是打卡地图，是用双脚写下的旅途篇幅；

第16州，北卡罗莱纳，我已签收！
