# Wisconsin English Practice Voice Audio

Place the 29 MP3 voice clips for `wisconsin-english-practice.html` in this folder.

Expected filenames:

```text
01.mp3
02.mp3
03.mp3
...
29.mp3
```

The current clips were generated with `en-US-BrianNeural` for a more natural read-along voice than the browser default.

The page checks this folder first. If a numbered MP3 is missing, that sentence falls back to the browser voice.
