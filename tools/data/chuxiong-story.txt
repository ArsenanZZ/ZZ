# 前言｜周末去楚雄，先逛吃，再跑马
六盘水跑完之后，回国的第二场马拉松，我来到了云南楚雄。上一场用了五小时二十分，这次想跑快一点。不过翻翻赛前一天的照片，吃米线、爬福塔、逛古镇、看夜景，一件都没少干。像不像来比赛的不好说，像来旅游的倒是真的。
@18-6
楚雄在云南中部，是楚雄彝族自治州的州府。这里的彝族文化不是只放在介绍牌上，车站外的装饰、古镇的街巷、夜里的舞蹈，还有比赛路边的加油队伍，一路都能碰到。这个周末，我就沿着这些地方走了一圈。
计划很简单：周六到楚雄，领装备，出去玩；周日跑全马，跑完赶火车。有人劝我再去大理玩两天，我也想，但周一还得上班。周末能塞多少，就先塞多少吧。
@13-5
# 夜到昆明｜帽子忘了，晚饭不能忘
到昆明南的时候，天已经晚了。我对着镜头说的第一件事是：“帽子忘带了。”行程刚开始，就先漏了一样东西。走出车站又觉得凉，跟想象中八月的天气不太一样。
晚上还是要吃点东西。摊位上冒着热气，烤架和小锅排在面前，人坐下来，注意力自然就从行李转到了吃的上面。我的这趟云南周末，先从夜宵开始。
@01 01-2
第二天是8月1日。早晨7点07分，我又打开相机，准备赶7点50分的火车。昨晚只睡了四个小时，自己还说“睡得还可以吧”。这么说也没错，至少睡着了。
街边的小餐馆已经开门，招牌上写着小锅米线。我一边走一边想，要是再早起一点，还能坐下来吃一碗。可我又不想起那么早，只好先去赶车。
@02
# 早班火车｜还没开跑，先遇上跑友
去楚雄的车上遇到了跑友，很自然就聊起了马拉松，也聊拍摄设备。画质好的机器往往有点分量，出去玩拿着还行，跑步时带上四个小时，就是另一回事，所以比赛还得选小一点的。
聊到有人已经把中国很多地方跑过一遍，我是真觉得厉害。原声里我说：“缘分，在火车上基本上也是缘分，就马拉松这点挺好的。”大家原来并不认识，因为同一场比赛，话就接上了。
@02-1 02-2
窗外是田地、村庄和压着云的山。到了楚雄，车站前已经有比赛周末的热闹。拖箱子的、背包的、穿跑步衣服的，往同一个方向走。
@03-1 03-2
我问工作人员有没有马拉松接驳车，得知9点半有车，赶紧问清楚在哪边等。出站就能接上赛事交通，对这种拎着行李来跑一场、跑完又走的人，实在很方便。
@03-3 03-4 04-1
# 领物现场｜先问清楚，箱子能不能存
坐了大约半小时车，终于到了领装备的附近。车上挺挤，到了现场又是一片帐篷和跑者。人还没开始跑，马拉松周末的气氛已经起来了。
@05-1 05-2
我最关心的却不是号码布好不好看，而是第二天能不能存箱子。跑完要直接去车站，如果还得绕回住处取行李，时间就麻烦了。领物的时候先把这件事问清楚，第二天才好安排。
@05-2-11 05-3 05-4
领完装备，现场还有小礼物，也有不少展位。啤酒、食品、品牌活动，旁边还有人在直播。看着这一圈，确实很难做到拿完号码布就立刻走。
@06-1 06-2 06-3
展位的招牌都挺会说话，有给跑者加油的，也有把马拉松和吃喝连起来的。我站在太阳底下，已经开始担心：“明天如果这个天儿就废了，明天应该不会这么热吧？”
@06-4 06-5
有人问我是不是回广东休息，我说回去上班，周一上班。对方劝我干脆去大理再玩两天。我说去过了，主要还是没时间。有的人能一路玩下去，我们这种周末出门的，得记着返程那班车。
@07-1 07-2
# 中午先吃｜房间没好，米线先上
到了住处，房间还没完全打扫好，那就先找吃的。我上一次来云南还是2019年，隔了这么久，这回又想找些当地的东西尝尝。
开发区农贸市场附近看着餐馆不少。对着一排招牌挑来挑去，最后还是坐下来吃米线。小锅里面有肉，也有蘑菇。我对着镜头念叨：“在这边吃菌，吃菌。”到了云南，嘴上已经很自觉了。
@08-1
吃完在附近缓一缓。街上有这样带棚的小车，酒店、市场、餐馆都挤在这半天的行程里。等房间收拾好，换上比赛的衣服，下午继续出门。
@08-2
# 福塔公园｜两块钱，上去看看楚雄
下午先去福塔公园，再去彝人古镇。下车才发现，到塔下面还得往上走。赛前一天说要保存体力，到了景点，腿又不由自主地开始加班。
@09-1 09-2
现场的票价牌写着两块钱。我一边往里走，一边说上面应该能看到整个城市，等会儿上去看看。一路停下来拍照，其实并没有觉得爬了多高，时间不少是花在镜头上的。
@09-4-1
福塔所在的地方，过去有一座锁水塔。现在看到的福塔是在原址重建的，2004年竣工。塔的飞檐一层叠一层，红色栏杆、灰蓝色装饰，从下面仰头看，跟登上去往外看，是完全不同的两种感觉。
@10-2
到了高处，楚雄的楼房铺在山间，远处还是一圈山。之前刚到车站，只知道又到了一个城市；站在这里，才看得出城区和山之间的关系。
@09-3 09-4 10-4
低头还能看到公园里的场地、屋顶和大大的“福”字。旅游的时候我就喜欢这样上上下下看，同一个地方，多换几个方向，照片也不一样。
@09-5 09-6
塔看了，照片拍了，摸摸旁边的浮雕，再在牌坊前留一张。接下来去彝人古镇，找点吃的，再看看晚上有什么热闹。
@10-1 10-3
# 彝人古镇｜跑马之前，先把逛吃完成
到了彝人古镇，第一感觉是街上已经有很多人。这是一处把彝族文化、旅游和商业放在一起的街区，不能把它当成一座原样保存、没人打扰的老村子。来这里就是逛街、看建筑、找吃的，挺直接。
@11-1
入口过去，摊位一个接一个。小吃、烤串、玩具、来来往往的游客，抬起相机，画面里总有人。白天的古镇有白天的热闹，先慢慢走一遍。
@11-2 11-2-1 11-2-2
路边的摊主一边烤一边招呼客人。我中午才吃过米线，到了这里，还是会顺着香味多看两眼。跑马周末常常就是这样，计划里写着比赛，照片里留下一堆吃的。
@11-3 11-4 11-5
坐下来继续吃。东西是不是都合口味？也没有。视频里第一句评价就是“好咸”，吃到后面又说肉有点肥。另一样蘸了糖的，感觉还行。自己出来玩，吃到了就照实说，不用每一口都“太好吃了”。
@11-6 11-7
# 逛到天黑｜灯亮起来，又舍不得走
天一黑，古镇又换了个样子。灯笼、招牌、屋檐上的灯，一起把街道照亮。白天刚走过的地方，晚上还想再拍一次。
@12-1 12-5
有穿着民族服饰的人，也有临街的店铺和围在一起看热闹的游客。我在里面走走停停，原本说来看火把节，后来发现单是逛这些街巷，就已经用了不少时间。
@12-2 12-3 12-4
街上人多了，车也开始堵。我经过星光夜市，又觉得这边没有刚才那么多人。每个地方的热闹程度还真不一样，隔一条街，感觉就变了。
@12-6
# 再加一站｜金色大鸟下面，还有人在跳舞
已经逛到晚上了，我还是想再去看看太阳历文化园。不去总觉得有点遗憾，那就再多走一站。门口那座大建筑特别扎眼，几何形的骨架一层叠一层，顶上是一只金色展翅的大鸟。
@13-1 13-4-1
这里说的是彝族十月太阳历文化园。最先吸引我的还是眼前的建筑和灯光。走近了看，跟远远看到的轮廓又不一样。
@13-4
里面有人跳舞，衣服上的绣花和头饰都很好看。我还对着镜头纠正自己：不是普通广场舞，是火把节的舞，“但是没有火把”。当晚看到了大家跳舞，也逛了夜里的园子，祭火大典却没赶上。
@13-2 13-3
到了门口，我还在说，祭火大典应该就在这边，可惜自己没有时间再来了。地方挺好看，晚上也成了市民休闲的场所。再待下去，明天跑步就更没睡头了，出门叫车，回去。
# 比赛清晨｜拖着箱子去起点
8月2日，楚雄马拉松。早上出门最重要的任务，是把箱子存上。昨天已经问过可以存，今天还是得实际办完才行。叫车起初不太顺，好不容易叫到一辆，显示离我还有1.8公里，那就等一等。
@14-1
到了起点附近，拖着箱子去存包，结果比我想象的顺利。我在视频里连着说了几次“还挺好的”。这件事解决了，跑完就可以直接去赶火车，不用再回头折腾。
@14-2 14-3
起跑前稍微下了点小雨，感觉天气还不错。现场跑友聊天，有人说自己从江西南昌来，跑马八年了，我接着说自己已经跑十年，大学就开始跑。不同地方的人又聚到一条起跑线前。
@14-4 14-5 14-6
# 起跑｜吃饱了有力气，差点迟到也是真的
人一多，又开始觉得闷热。我这边刚说天气还好，站进人群里就变成了“好热，好闷啊”。比赛前的体感，真是走几步就会改口。
@15-1-1 15-2-0
2026楚雄马拉松从州文化中心广场出发。我穿着绿白横条的上衣，头上也是绿色的帽子，拍照时在人群里还算好找。红色的起跑拱门前，举手、自拍、打招呼，一项都没耽误。
@15-1 15-2-1 15-2
起跑以后我说：“吃饱了再跑，真是有力气啊。”后面又跟了一句：“虽然差点迟到了。”早餐的好处享受了，赶时间的代价也一起承受，算是很公平。
@15-2-2-1 15-2-3
前面是宽阔的城市道路，两边站着看比赛和加油的人。全马、半马的跑者挤在一起，刚出发这一段，镜头往前一转，全是五颜六色的衣服。
@15-2-2 15-3 15-4 15-5
# 前半程｜看公里牌，补水，继续往前
两公里、三公里，先把节奏慢慢跑起来。路边已经架好了相机，摄影师守着跑者经过。自己拿设备拍赛道，也会被别人的镜头拍进去，这点挺有意思。
@16-1 16-2 16-2-1 16-2-2
到五公里，我吃了第一个能量胶，提醒自己早点补。这里也不是只有跑步的人忙，供水站的志愿者不停递杯子，路边穿民族服饰的人站成一排给大家加油。
@16-3 16-4 16-5
八公里的牌子过去，我在九公里之后录了一句“折返了”。这场路线有几段折返，从城区道路跑出去，再换一侧回来。看着对面跑者，也知道自己还有哪一段要去。
@16-6 16-4-1 16-7
路上还是会对着相机说加油，也顺手记一下到了哪里。十四公里继续往前，绿树、楼房、路灯往后退，暂时还不用想最后那几公里会是什么样。
@16-8 16-9 16-9-1
# 半程之后｜目标开始变小
补给站到了，喝点水再走。摄影师拍到的是跑过来的样子，自己的镜头里经常只剩下一口水、一排杯子和下一块公里牌。两种照片放在一起，才比较像当时真正经历的比赛。
@17-1 17-2 17-3
我在半程前说“马上半程了”，到了二十一公里又说“有点累了”。从这时候开始，话越来越短，主要内容就是报个公里数，再给自己加个油。
@17-2-1 17-2-2 17-4 17-4-1
前半程绕过城区，后面还要沿着彝海一带继续跑。二十四公里的牌子、前面的路、远处的山，都是很普通的赛道画面。可跑到这里，普通的公里牌也值得拍一张，毕竟又少了一公里。
@17-5-1 17-5
二十五公里到了，前面还有一段棚架下的赛道。彩色的装饰和火把节图案很醒目，路边还是有人忙着递水、收杯子。自己开始累了，看到这些人还在站着，就再往前走走。
@17-6 17-6-1 17-6-2
# 27公里以后｜说好的雨呢
到二十七公里，太阳出来了。我第一反应就是：“热啊。”二十八公里又说了一次。早上那点小雨没有接着下，反而越跑越晒，赛前担心的事还是碰上了。
@17-6-3 17-6-3-1
原声里还有一句：“说好了下雨也没下，还挺热。”这当然不是跟天气讲道理，就是跑累了以后忍不住念叨。看一眼前面，先把目标定到三十公里，再说下一段。
@17-6-4 17-6-4-1 17-6-4-2
后半程开始跑跑走走，我对着相机说：“跑一走三吧。”说完发现不对，赶紧改口：“不是，跑三走一。”自己给自己安排战术，差点连顺序都安排反了。
@18-1-1 18-1
再往后，目标变成三十二点五公里，然后是三十五公里。大的目标有点远，就切小一点。这里跑一段，那里走一段，再喝口水，也还在往前挪。
@18-2 18-3-1 18-3
# 最后两公里｜最后一哆嗦
四十公里，路边的加油队伍还很精神，彩色衣服和头饰排成一行。我停下来和公里牌留个影，再继续跑。照片里能举手，不代表腿不累，拍完还得自己把最后两公里跑完。
@18-4-0-0 18-4-1-0 18-4-1
路边的水雾把一段路打湿，前面还有四十一公里的牌子。这时候我已经不太说完整句子了，主要就是“加油”“还有两公里”“最后一哆嗦”。这些话没什么文采，当时却只能靠它们往前顶。
@18-4 18-5
跑到四十一点五公里，我说已经四个小时了。原本还想破四，现在也不用算了。稍微走一走，缓一下，再去冲线。看见终点前的两百米牌子，终于知道这次是真的快到了。
@18-5-0 18-5-1 18-5-2
# 完赛之后｜奖牌到手，下一项是火车
跑完对着相机总结，我说用了四小时零六分钟，本来以为能破四，后半程崩了，太累，也太晒。可是和六盘水的五小时二十分相比，这次已经快了不少。“其实还OK”，这是我当时的原话。
@19-1 19-2
奖牌是金色的，顶上有牌坊造型，中间一圈圈纹样，下面还有火焰和花。拿在手里拍两张，再看看背后的楚雄站，这趟比赛也算有了个交代。
我没有在终点休整多久，还得赶火车。幸好大巴能送到车站，上车以后看看时间，到了车站是12点22分，还来得及。我连着说“挺好的，挺好的”，这次是真心感谢这个接驳安排。
@18-67 19
# 返程｜在高铁上把饭补回来
车站里又是一批刚跑完的人，有的背包，有的拖箱子。前一天大家从不同地方来，今天再从这里散开。站台、检票口、白色的高铁，又接回了周末出发时的画面。
@19-3 19-3-1 19-4
上车了才有空坐下来吃点东西。比赛时吃的是胶、喝的是水，真到了饭点，还是这一盒饭来得实在。边吃边看车窗外的田地和山，刚才在路上晒着跑步，现在总算可以坐着了。
@19-5 19-6 19-7 19-8
这个周末，昆明的夜宵、楚雄的米线、两块钱登福塔、古镇逛到天黑，全马后半程又晒得直喊热。最后没破四，火车倒是赶上了，周一该上班还得上班。
回国第二场马拉松跑完了。身体累，照片不少，想吃的也吃了，想看的地方大部分都去了。下次要不要少安排一点赛前活动？先这么说吧，等到了下一个城市，大概还是会想出去看看。
