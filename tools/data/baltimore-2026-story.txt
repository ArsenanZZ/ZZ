# 第三次来｜这次不做报告，来跑马拉松
巴尔的摩，这个城市我第一次听说，大概是在2019年。那时候追《侣行》，跟着张新宇和梁红的镜头看他们穿越美洲，其中一站就是这里。我记得当时最深的印象，不是什么海鲜、港口，是治安。连去过中东战场的270，到了巴尔的摩都觉得危险，这个名字我就记住了。
@026 027
后来我自己也来了美国，居然陆陆续续来了巴尔的摩两次。一次参加学术会议，一次参加冲击力学的短期培训，都在约翰斯·霍普金斯大学。不过我自己来的那两次，感觉都还不错，也没觉得有多危险。出门注意一下，不往自己不了解的地方乱钻就好了。巴尔的摩离华盛顿也近，我还租车过去转过。就是去华盛顿那条路，车是真多啊，导航经常红着，本来一个小时左右就能到，堵起来就不好说了。
这次第三次来，终于不是开会或者培训了，来跑个马拉松。
朋友推荐过好几次巴尔的摩马拉松了，特别是那个螃蟹奖牌，一直是这个比赛的signature。我一直想来，但每次都没安排上。终于，今年十月份有机会过来跑一跑了。
# 马里兰｜地图上不大，东西倒是不少
马里兰，Maryland，我的Run50第37州。以前看美国地图，我的注意力老被那些面积特别大的州吸走，这个州反倒没那么显眼。这个州面积不大，地形倒是不少：西边是阿巴拉契亚山地，往东有农田、城市、湿地和海湾，再往东还有大西洋海滩。
@023 024
所以它还有个外号，America in Miniature，美国缩影。切萨皮克湾伸进州里，沿岸的海鲜也很出名。州府是安纳波利斯，Annapolis，不是我们这次去的巴尔的摩。我们从西边开过来，先看山，再看海湾，一个州里就能换好几种风景。
@025
说到这里，螃蟹肯定绕不过去。切萨皮克湾的蓝蟹很有名，马里兰还专门把蓝蟹定成州甲壳动物。蒸蟹、蟹饼，到处都能见到，马拉松奖牌也做成了螃蟹。我其实不怎么爱吃螃蟹，但这个金色的奖牌，我还是很想要的。不能吃没关系，但能收藏啊。
比赛叫Baltimore Running Festival，巴尔的摩跑步节，今年是第26届。全马、半马、十公里、五公里都有，不一定非得跑全马才能参加。我这次跑全马，Siqi跑十公里，跑完还要一起赶去新泽西呢。
# 周五出发｜尿点和充电，无缝衔接
Baltimore Running Festival在周六比赛，所以为了这场，我专门请了一天假。其实能不请假，我一般是不请假的，毕竟一直醉心工作嘛。这大概也是为什么，这个螃蟹让我惦记到现在。
周五我和Siqi天还没亮就出发了，看了一下时间，六点四十一。领装备晚上七点结束，开过去加上充电要十一到十二个小时，时间也没有特别宽裕，还是早点走吧。
@001 002 013

@003 004
开到列克星敦附近，城市已经醒来了。黄色校车出来了，上班的轿车也多了，路口一辆接着一辆。我们这是请假去跑步，人家还是正常上班上学。
@005 006 007

@008 009 010

@011 012

@015 016

# 到巴尔的摩｜高速开完了，停车才费劲
终于进城了。远处高楼一层一层冒出来，高架桥绕来绕去，旁边还有一大片水。当时我都没弄明白这到底是湖还是海，第一反应就是：这城市，看着挺繁华啊。
巴尔的摩靠着帕塔普斯科河的潮汐河口，往外通向切萨皮克湾。我们跑步会经过的内港是城市很热闹的一面，真正的港区还向外延伸。海鲜、货船、工业码头，都是这个港口城市的一部分。
@028 029
说到港口，我还想起那次大桥被撞塌的新闻。不是去年，是2024年3月26日。“Dali”号集装箱船撞上Francis Scott Key Bridge桥墩，造成桥梁坍塌，六名道路施工人员遇难，航道和周边交通也受到严重影响。当时新闻里一直在说这件事，来了才知道港区有这么大。
@030 031
街边一座接一座老建筑，红砖墙、教堂尖顶，还有那个方方正正的大钟塔。钟塔叫Bromo Seltzer Tower，挺好认。后来查到，它1911年建成时还是巴尔的摩最高的楼，造型参考了意大利佛罗伦萨的旧宫。现在里面有艺术家的工作室。看着不起眼的老楼，一查都有一百多年了。后面又是高楼，夹在一起看，整个城市还挺有层次的。
@032
路面上还时不时冒出一大团白汽，有点纽约那味道了。后来查了一下，这里有地下区域蒸汽供能管网，雨水或地下水接触热管道，也会产生这种白雾，并不都意味着管道漏了。我们到的这天又下过雨，街边竖着的排汽管更显眼。
@033
取装备在downtown的Baltimore Convention Center，会展中心。我们花了好大的力气才把车停好，明明地方就在附近，开车却要绕来绕去。开了一整天了，到了这里还得找车位，确实有点烦。
@034 035
好在最后赶上了。里面挺热闹，领号码布、拿衣服，分区和队伍都很清楚。我领全马的，号码2790，Siqi跑十公里。我们还换了换衣服尺码，逛了一下展台。Siqi买了顶帽子，说第二天会冷，这几天降温了。
@036 037
领完出来又下雨。还有一次，本来想绕过去接Siqi，导航一带，开上高速了，只能再绕回来。这下好了，还得再开一圈。
@038
趁着充电，我们又去超市买点吃的。里面一面墙画得花花绿绿，人物、图案挤在一起，还挺好看。巴尔的摩的壁画确实不少，当地也长期有社区壁画项目。这面墙也拍下来了，第二天跑比赛，沿路还能看到不少壁画。
@039
Airbnb挺干净，也舒服，到了就把第二天的东西收拾好。开了一天车了，明天还得跑马，吃点东西就赶紧休息了。
# 比赛早晨｜从一个体育场走到另一个体育场

@040 041

@042 043

# 要起跑了｜人还没跑，脑子先飞了
全马和十公里八点出发，起点在Paca Street和Camden Street附近。那个绿色的Pickles Pub招牌特别显眼，前面是Brooks Robinson的雕像。周围全是人，白色的气柱往上喷，彩纸飘起来，上面的美国国旗也一直在动。
@051 052 053

# 跑进公园｜阿森纳出来了
前面还有动物造型的吉祥物跟跑友打招呼。比赛里看到这种，还是会忍不住拍一下。路上我还看见穿科莫队Nico Paz球衣的跑者，我这边依然阿森纳在身，出门跑马也不忘支持球队。
@061
先说一下路线，全程26.2英里，42.195公里。从市中心往北，跑进Druid Hill Park和动物园，再折回来经过港口，后半程往东北穿社区，到Lake Montebello绕一圈，最后回内港冲线。公园、老街、港口都能跑到，可别以为在水边就都是平路啊，后面那些坡，真不少。
@062
这里的Druid Hill Park，德鲁伊山公园，1860年就开放了，马里兰动物园就在里面。动物园1876年开门，正好今年150周年。这才知道，里面的动物园都开了一个半世纪了。
和十公里队伍分开后，人没那么挤了。蓝衣服脱掉，黑色阿森纳终于露出来。看到旁边有摄影师，还是比个手势吧，照片总得有。
@063 064
树多起来了，路边都是秋天的颜色。前面有草地，有开阔的水面，远处还能看见城市。刚才还在红砖房子中间穿，这会儿一下变成公园，还挺舒服。
@065 066 067

这时候腿也还行，能正常跑，还能一边跑一边看看周围。阴天不晒，偶尔有风，比赛前担心冷，真跑起来倒是合适。

# 红砖街道｜一边跑，一边认楼
离开公园，又钻回街道。高高的教堂塔楼远远就能看见，走近了，石头墙、尖屋顶都挺有意思。巴尔的摩的教堂是真的多，开车看见，跑步又看见。
@070 071

@072 073

@074 075
# 闻到糖厂｜鼻子也跟着逛了一圈
跑到港口这一边，先看见巴尔的摩工业博物馆旁边的大吊机。前面还是教堂和居民楼，到了这儿，烟囱、厂房、起重设备都出来了。这个港口不是摆几艘船给游客看的，确实有工业城市的底子。
@076
再往前，一股味道飘过来，有点像发酵的面包。我边跑边猜，这是什么厂？看到Sugar，才反应过来，糖厂啊。这里是Domino在巴尔的摩的炼糖厂，1922年就开始生产，直到现在还在运转。厂房和烟囱就在赛道边，隔着赛道都能闻到味道。
@077
十英里、十一英里，一个牌子一个牌子往前过。看了一圈工业区，又回到街上。看到什么就拍点什么，房子拍了，自己也拍了，过了这一段又有别的东西看。
@078 079
# 回到内港｜这个背景，不拍不行
接近半程，跑回市中心和Inner Harbor。高楼、广告牌、港湾，全挤到一起，视野一下开了。这一段很热闹，我对着镜头还说了，有点纽约的感觉。
@080 081 082
水边那个带大吉他的红砖建筑很抢眼，是Power Plant里的Hard Rock Cafe。Power Plant以前真是发电厂，现在变成吃饭和逛街的地方，烟囱和老砖墙还留着。远看是厂房，近看又是餐厅。
@083 084
红砖、拱窗、大烟囱，后面又是现代高楼，老建筑和新楼挨在一起，我又多拍了几张。
@085 086
水里还停着一艘白色大船，写着COAST GUARD，船号37，是内港保留的历史海岸警卫队舰艇。后来查了船的资料，它1936年服役，做过海上巡逻、搜救，也经历过二战，1986年才退役。就这么停在港口边，没查资料之前，还真不知道它有这么多经历。
@087
跑到二十公里左右，还是想在这里给自己来一张。港口的背景确实好看，就是现在还不能停下来慢慢逛，还得接着跑呢。
@088
# 后半程｜Be Kind，然后开始爬坡
离开内港，又进社区。路口突然冒出一面彩色墙，大大的BE KIND，旁边画着花、鸟和各种图案。整座城市看了那么多红色、灰色、黑色，这种颜色一出现，真让人眼前一亮。
@089 090
这一带有些房子还挺精致，小店、街角、门面各有各的样子。再往前，又会遇到明显老旧的街区。巴尔的摩就是这样，几条街之间，感觉可以差很多。
@091 092
我想起上次开车来，有一次绕进一片街区，房子的门窗都被木板封住了，路况也不好。那时候我不太熟悉，自己越开越不踏实，七绕八绕才出来。这回赛道也经过一些老旧的街区，看到那些房子，就想起上次开车绕路那一趟了。
@093 094
然后就开始爬坡了，上去一点，再下来一点，还没完没了。官网专门提醒过十七到十九英里这段有“伤心坡”，跑到这里就知道了，确实上上下下的，后半程跑起来还是有点累。
@095
路上还有一栋屋顶破了洞的老石头建筑，远看像个小教堂。我当时还想，这看着都快撑不住了，居然还留着。后来对照位置和照片查到，是Clifton Park Valve House，十九世纪修的供水阀门房，过去负责调节水库之间的水流。一个管水的房子都修成这样了，美国这些老城市，还真有不少历史啊。
@096 097
我开始跑跑走走。明天还要跑新泽西，今天没必要非跟这些坡较劲。看到摄影师，再把手势做起来。照片里看着还行吧，其实刚才还在走呢，哈哈。
@098
# 绕湖一圈｜景色还行，腿不太行
终于到了Lake Montebello。看了眼距离，三十一点八公里左右，快二十英里了。湖面很开阔，跑友沿着边上排成一条线。到了这里，倒是不用想往哪儿拐，跟着绕就行。名字叫Lake，它其实是人工水库，1881年就投入巴尔的摩的供水系统。前面那个破屋顶的阀门房管供水，这里也是水库，原来这一路不光是公园和住宅区。
@099 100
二十英里的牌子，看起来才“20”，实际上已经三十二公里左右。剩下还有十公里，平时觉得也没多少啊，现在怎么还这么远。
@101 102

# 第37州完成｜明天接着跑
这已经是我第三次来巴尔的摩，每次都不太一样。2022年来开学术会议，那时候还青涩，拿英文做报告，紧张得不行。2023年来参加高速冲击的短期培训，和各地做实验的人、MIT的大牛一起，还有机会跟洛斯阿拉莫斯的学者聊UFO，挺有趣。我还租了车去华盛顿，跑到国会大厦、林肯纪念堂和白宫旁边。
这次终于是来跑马。以前在大学、会场和实验室周围活动，这回跑进公园，经过糖厂，绕过湖，也看见了破旧房子、彩色墙和热闹的港口。一场马拉松跑下来，比前两次来走的地方多多了。
以前从纪录片里记住的是治安，这次自己遇到的，还有赛道边加油的人、帮我拍照的跑友，以及教我开螃蟹、分苹果的大哥。前一天去超市，还有小朋友用中文跟我说“你好”。
后来查资料才知道，巴尔的摩近年的凶杀和枪击数据也在下降。至少我这次的感觉，和当年隔着屏幕看的印象很不一样。一路遇到的人挺友好，比赛也跑得挺开心。就是坡，真的多。
